3. Screens and navigation

3.1 Navigation structure

Bottom tabsHome · Artists · Create (+) · Events · Calendar
Header (Home)Menu · Messages · Map · Notifications
Side menuProfile, Dashboard, Switch workspace, Pro tools, My events, Events near me, Communities, Friends, Music lessons, Bookings, Tickets, Wishlist, Payment methods, Notifications, Pro plan, Help, Support cases, Admin (staff), Settings, Log out

Routing uses Expo Router (file-based). Every file in mobile/src/app is a screen; _layout.tsx files define navigators. The URL path of a screen is the same on all three platforms, so deep links and web URLs share one scheme: domtak://event/bunker7 on mobile and https://<web-domain>/event/bunker7 on the web. Signed-out users are redirected to /login?next=<path> and return to the path after signing in.
