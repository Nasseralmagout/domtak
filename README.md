# Domtak

Music-first social platform connecting musicians, event organizers, venues and fans in Berlin.

- **`mobile/`**: the Android app (Expo / React Native). See [mobile/README.md](mobile/README.md) to run it, build an APK, and see the full screen list.
- `App.jsx`: route map of the existing web site.
- **`docs/Domtak-Technical-Handbook.pdf`**: implementation, deployment and service-activation guide for the frontend and backend teams (source in `docs/handbook/`).
